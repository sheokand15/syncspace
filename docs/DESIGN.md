# UI and Interaction Design

Brand: SyncSpace, calm and focused. Use a warm near-white canvas, deep ink text, a restrained blue/teal action color, and amber/red only for connection/error state. Use a readable system sans stack, 4 px spacing base, 8 px corner radius, subtle borders, and visible focus rings.

The app shell has a compact workspace navigation rail, document list, and editor surface. Landing and auth pages explain shared editing and offline behavior and provide accessible sign-in/register forms. Dashboard shows recent documents, workspace selection, create action, loading/error states, and a helpful empty state. Editor has editable title, a small semantic formatting toolbar, document body, collaborator initials, live cursor/selection decorations, copyable URL, share controls, and an honest provider connection/sync state. A persistent offline banner appears only when the browser/provider reports disconnection.

Deletion requires confirmation. Buttons have labels, keyboard focus and shortcuts are discoverable; status is communicated with text, not color alone. Responsive behavior collapses navigation on narrow screens and keeps editor controls operable. Do not show fake users or optimistic “saved” status without provider/persistence evidence.
